# AGENTS.md: MK Engineering Cooling website

Guide for AI coding agents (Codex, Claude Code, etc.) working in this repo. Read this first, then the file in `docs/` that matches your task.

## What this is

The public website of **MK Engineering** (commercial refrigeration supply, installation and service; offices in Madurai and Trichy, Tamil Nadu). Live at **https://www.mkengg.in**. `mkengg.in` redirects to `www`.

The site is **static HTML generated by Python**. There is no server, database or JavaScript framework. `src/build.py` reads captured content plus config and writes the finished site into `dist/`. Vercel serves `dist/`.

The product catalogue covers three brands MK Engineering deals in:

| Brand | Products | Source of data |
|---|---|---|
| Western Equipments (Western Refrigeration) | 192 (140 with detail pages) | Capture of westernequipments.com in `source/` |
| Symphony | 65 air coolers and tower fans | `fetch-symphony.py` → `source/symphony/` |
| Elanpro | 206 commercial and pharma refrigeration | `fetch-elanpro.py` → `source/elanpro/` |

## Commands

```bash
python src/build.py                              # regenerate dist/ (about 25 s; first run converts images, a few minutes)
python validate.py                               # check dist/ for missing assets and broken internal links
python -m http.server 8080 --directory dist      # preview at http://localhost:8080
python fetch-symphony.py                         # refresh Symphony data and photos (network)
python fetch-elanpro.py                          # refresh Elanpro data and photos (network)
```

Python 3 with `beautifulsoup4`, `lxml`, `jinja2`, `markupsafe` and `Pillow`. There is no requirements file and no test suite: `validate.py` plus a visual check in a browser is the test.

**After every change: build, validate (expect `missing_assets: 0, missing_link_targets: 0`), look at the affected pages, then commit `src/` changes together with the regenerated `dist/`.** `dist/` is committed and is what goes live.

## Deploying

Pushing to `main` on GitHub (`SlunkySloth/MK-engineering-Cooling`) deploys automatically to Vercel (project `dist`), which serves `dist/` as configured in `vercel.json`. Do not push to `main` without the owner's go-ahead. Details: `docs/deployment.md`.

## Where things are

| Path | What it is |
|---|---|
| `src/site.json` | Company name, logo, phones, emails, locations, social links, brand and client logos, menus. **Edit this to rebrand.** |
| `src/build.py` | Build entry point (`Site` class): extraction, rendering, search index, compare data, images |
| `src/extract.py` | Reads the Western capture in `source/` (products, categories, pages, blog) |
| `src/symphony.py`, `src/elanpro.py` | Turn captured brand data into products in the shared shape |
| `src/mk_content.py` | MK Engineering's own text: home hero, About and Service pages, rewording of captured Western self-descriptions |
| `src/images.py` | Converts images to responsive WebP in `dist/img/` (cached between builds) |
| `src/templates/` | Jinja2 templates; `base.html` has the header, mega menu, drawer, footer and dialogs |
| `src/assets/` | The only CSS (`site.css`) and JS (`site.js`) files, plus the Manrope font |
| `source/` | Read-only input: the Western capture, `symphony/`, `elanpro/`, and MK's own assets in `wp-content/uploads/mk/` |
| `dist/` | Generated output. Never edit by hand; it is wiped and rebuilt each build (except `dist/img/`). |
| `brand/logo-options/` | Logo concepts drawn during the project (not used by the site) |
| `mirror.py`, `finalize.py`, `repair-assets.py` | One-off tools from the original capture; not part of the normal build |

## Rules that matter

- **Never show prices** for Symphony or Elanpro. Prices exist in the captured data but are deliberately not published.
- **Keep the design language**: tokens in `:root` of `site.css` (brand `#673fff`, ink `#0b1b2b`, Manrope, 16px radius), the card and tile styles, and the brand-switching mega menu. New pages should reuse existing templates and macros.
- **One CSS file, one JS file, no frameworks or CDNs.** Pages must work without JS; JS only enhances.
- **Escape anything from captured data.** Templates autoescape; only use `|safe` on values the extractors already sanitised.
- **Don't edit `source/` by hand** except MK's own assets in `source/wp-content/uploads/mk/`. Change behaviour in the extractors instead.
- **Rights:** the owner is an authorised dealer for these brands. Content copied from manufacturers stays manufacturer content; don't invent claims about MK Engineering.
- Match the surrounding code style: compact Python, short comments only where something is non-obvious.
